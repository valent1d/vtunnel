Pleasant local tunnels powered by Cloudflare Tunnel.

Install on Linux (or macOS without Homebrew)

$curl -fsSL https://vtunnel.valent1.dev/install.sh | sh

Install on macOS (Homebrew)

$brew install valent1d/vtunnel/vtunnel

Then

$vtunnel onboarding
